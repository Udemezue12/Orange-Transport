About ORANGE Transport

ORANGE Transport is a full-featured transportation management platform I built to support the complete passenger and operational journey. The platform handles routes, terminals, scheduled trips, vehicles, drivers, seat allocation, reservations, bookings, fares, and passenger management, while also providing customer service capabilities to help passengers receive support and resolve issues throughout their journey.

Built with Java and Spring Boot, the platform incorporates secure authentication and authorization, role-based access control, payment processing, booking and reservation management, driver and terminal operations, customer service, notifications, and other supporting services. Security is a major part of the system, with protections around authentication, authorization, CSRF, JWT-based access, secure payment workflows, and sensitive user operations.

Security at the Core

Security is a core part of ORANGE Transport, with authentication, authorization, request protection, secure payment handling, and controlled access to sensitive transportation operations built into the backend.

Application Security
  • JWT-based authentication
  • Role-based access control (RBAC)
  • CSRF protection
  • Protected sensitive operations
  • Secure authentication workflows
Authentication & Access Control
  • Spring Security integration
  • Protected API endpoints
  • Role-based authorities
  • Secure login and session workflows
  • Passkey / WebAuthn support
Payments & Operational Security
  • Secure payment initialization
  • Idempotent payment requests
  • Payment webhook handling
  • Refund processing
  • Controlled booking and reservation workflows
Security by Design: Authentication, authorization, CSRF protection, secure payment workflows, and access-controlled operations are considered throughout the platform.
